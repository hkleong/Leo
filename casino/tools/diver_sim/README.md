# 深海寻宝 simulator

5×3, 10 lines. 潜水员 (W) wild on reels 2–5; 宝箱 (M) carry a cash value; 3/4/5 船舵 (X) give 8/12/16 free spins.
In free spins every 潜水员 collects all 宝箱 on screen × level multiplier; every 4 divers level up (+10 spins, ×1→×2→×3→×8).

    node diversim.js 8000000

`divercfg.js` must match `DVC` in `casino/index.html`. Current numbers: RTP about 96%, a win every 3.75 spins,
free spins about every 108 spins worth about 48× the stake on average.
